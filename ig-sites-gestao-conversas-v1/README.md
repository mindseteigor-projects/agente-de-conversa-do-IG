# IG Sites — Gestão de Conversas v1

Esta versão substitui o projeto de bot por uma plataforma de organização e análise.

## O que NÃO existe
- Não conecta ao WhatsApp.
- Não possui API do WhatsApp.
- Não possui webhook.
- Não envia mensagens.
- Não responde automaticamente.
- Não existe botão de "Enviar".

## O que existe
- Dashboard.
- Cadastro/registro de conversas.
- Histórico de mensagens para consulta.
- Funil comercial.
- Busca e filtros.
- Anotações.
- Métricas de resposta, interesse, pedido de modelo e venda.
- Análise de tempo até primeira resposta.
- Armazenamento local no navegador.

## Como usar
Abra `index.html` no navegador ou publique os três arquivos (`index.html`, `styles.css`, `app.js`) em uma hospedagem estática.

A versão inicial usa dados fictícios e armazenamento local. Para colocar seus dados reais, podemos criar depois um importador de CSV/JSON ou uma tela para registrar as conversas manualmente.
